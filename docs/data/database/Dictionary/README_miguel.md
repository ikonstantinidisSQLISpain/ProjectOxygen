# Data glossary


* analytic: Holds all the information about the company organization.
    * units
    * departments
    * entities
    * service_lines
    * sites
    * societies
* cra: Holds the information about work logs, in other words, the time spent on each project by workers.
    * bilans
    * worklogs
* whoz: Holds data requested from Whoz [API](https://developer.whoz.com/) platform.
    * accreditations
    * certifications
    * profiles
    * skills
    * talents
    * users
* perso: Holds data about employees.
    * collab_status
    * leaves
    * workers
* project
    * ca_collab
    * financial
    * project_dataware
    * projects
* others: Anything that does not fall into the other categories or experimental.
