# Site

From introduction, a site is a location.

| Column | Type   | Description                   | Contraints | PK/FK |
|--------|--------|-------------------------------|------------|-------|
| id     | BIGINT | Identifier of the site.       |            |   PK  |
| name   | STRING | Name of the site.             |            |       |
| active | BOOL   | If the site is active or not. |            |       |
