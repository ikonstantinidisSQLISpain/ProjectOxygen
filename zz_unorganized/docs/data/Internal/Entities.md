# Entity

| Column | Type   | Description                      | Contraints | PK/FK |
|--------|--------|----------------------------------|------------|-------|
| id     | BIGINT | Identifier of the entity.        |            |   PK  |
| name   | STRING | Name of the entity.              |            |       |
