# Certification and Skill

This table holds the relationship between a certification and its skills.

| Column     | Type   | Description                      | Contraints | PK/FK   | Notes |
|------------|--------|----------------------------------|------------|---------|-------|
| cert_id    | STRING | Self-explanatory.                |            | PK / FK |       |
| skill_id   | STRING | Self-explanatory.                |            | PK / FK |       |
| concept_id | STRING | A FK to something we don't know. |            | FK      |       |
